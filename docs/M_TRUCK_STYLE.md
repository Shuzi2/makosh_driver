# M TRANS — візуальний стиль

Назва продукту: **M TRANS**. Логотип — відтворений за брендбуком маршрут у формі літери M з дорожньою розміткою та помаранчевою кінцевою точкою (static/brand/m-truck-mark.svg). Оригінальний SVG поки не надано.

Палітра: основний помаранчевий #FF5112, чорний #000000, графіт #20242A, білий #FFFFFF, фон #EEF0F4. Зелений використовується для успішних станів, теплий бурштиновий — для уваги. Шрифт інтерфейсу — Manrope, для технічних даних — JetBrains Mono.

Надалі зберігати легкі поверхні, чіткі підписи, піктограми одного стилю та короткі ненав’язливі переходи. Розміщення й робочі сценарії змінювати лише за потреби; враховувати вузькі екрани та системне налаштування зменшення анімації.
