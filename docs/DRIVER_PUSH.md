# Push-сповіщення водія

Сповіщення ставляться в чергу для пристроїв водія, коли йому призначають рейс, логіст змінює або скасовує рейс, змінює стан сервісного звернення чи відповідає на нього. Вони не містять номерів, адрес чи інших подробиць на екрані блокування. Черга надсилається окремим сервісом `push_worker`; відсутність зв'язку не заважає зберігати рейс. Доставка залежить від push-служби телефону та його налаштувань, тому не гарантується; у кабінеті залишаються звичайні повідомлення.

## Налаштування на сервері

1. Підключіть домен із дійсним HTTPS-сертифікатом та налаштуйте дозволені хости і CSRF для нього. Для Android також потрібен доступ телефону до сайту та інтернету; для iPhone сайт має відкриватися в Safari і бути доданим на початковий екран. Apple Web Push потребує iOS/iPadOS 16.4 або новішої версії. Система телефону та його push-провайдер також мають мати інтернет.
2. Збережіть резервні копії бази та завантажених файлів перед розгортанням. Секретні файли не додавайте до Git.
3. У корені проєкту зберіть образ `docker compose build web`. Якщо `WEBPUSH_PUBLIC_KEY` або `WEBPUSH_PRIVATE_KEY` вже задані, **не генеруйте їх повторно**: зміна пари зробить наявні підписки недійсними. Для першого налаштування виконайте у захищеному сеансі Ubuntu:

   ```sh
   umask 077
   docker compose run --rm --no-deps web python scripts/generate_webpush_keys.py > .env.webpush
   ```

   Додайте рядки з `.env.webpush` у серверний `.env` і додайте `WEBPUSH_SUBJECT=mailto:адреса-відповідального` із реальною службовою адресою. Захистіть файли правами `chmod 600 .env .env.webpush`; не публікуйте ключі та не надсилайте їх у чат. Надійно збережіть пару ключів разом з іншими секретами сервера.
4. Запустіть оновлені сервіси та міграції відповідно до правил розгортання проєкту: `docker compose up -d --build`. Перевірте стан `docker compose ps`, зокрема `push_worker`, і застосунку. `push_worker` повинен мати вихідний HTTPS-доступ до push-провайдерів Apple, Google, Mozilla та Microsoft.
5. Водій відкриває сайт на телефоні, входить у свій обліковий запис і в меню «⋯» натискає «Увімкнути сповіщення», після чого надає дозвіл. На iPhone спочатку: Safari → «Поділитися» → «На початковий екран», відкрити сайт з іконки та увімкнути сповіщення в ньому. Кожен телефон підключається окремо.
6. Перевірте на реальному телефоні: новий рейс, зміну рейсу, відповідь та зміну стану звернення, зокрема коли сайт згорнутий. Перевірте, що натискання сповіщення відкриває потрібний розділ, а після виходу з кабінету телефон не отримує нових повідомлень цього водія.

Телефон може блокувати повідомлення через системні дозволи, режим фокусування, економію заряду чи відсутність зв'язку. Точний час доставки операційна система не гарантує.
