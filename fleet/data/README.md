# Settlement catalogue

Source: user-supplied `kodifikator-07-07.xlsx`, sheet `Кодифікатор`.
Contains 29,703 settlement entries (categories C, X, M and K), including original KATOTTG codes. Region, district and community names are resolved by their codes, not by row adjacency. City districts (B) are not treated as independent settlements. Kyiv and Sevastopol retain their special hierarchy; missing community/district fields are not invented.

`settlements.json.gz` stores the original workbook SHA-256 for provenance. It is a local reference snapshot, not a live government feed. Existing trip addresses are never rewritten. Manual input remains available and is saved to that trip only.
